# PicMan v1.3.0 发布说明

## 打包时间

2026-11-02

## 一句话

**内存占用不再随图片张数增长**——以前处理 1000 张要吃掉几个 G，现在只跟并发数有关。

## 这版有什么

> 1.2.0 之后攒了 1.2.1 / 1.2.2 / 1.3.0 三个版本的改动，这里按「能感知到的程度」排。

### 最明显的变化

- **产物不再占内存**：处理完的图直接落盘（`~/Library/Caches` 下的临时工作目录），内存里不再保留副本。批次多大都不影响内存水位。导出、预览、单张下载会自动从磁盘读。
- **外观三档**：顶栏右侧「跟随系统 / 始终亮 / 始终暗」。默认跟随系统——系统是深色的一打开就是深色，系统切档时界面当场跟着变。
- **提示条重做**：成功提示 5 秒自动消失（**鼠标悬停时暂停**），警告和错误常驻需手动关。不再是一条一条翻页，改成最多同时显示 3 条。
- **进度条跑完给结论**：处理结束后不再一闪而过，原地显示「成功 N · 跳过 M · 失败 K · 耗时 X s」。有失败会转琥珀色，不谎报全绿。

### 新功能

- **完整重命名**：前缀 / 后缀 / 查找替换 / 序号（起始值、补零位数、连接符）/ 只用序号。ZIP 与目录导出共用同一套规则，序号按整批连续。
- **导出布局**：扁平化目录（只摊平最外层以内）、ZIP 按顶层文件夹分包、包名直接用文件夹名。
- **设置预设**：画质优先 / 均衡 / 小体积 / 网页优化 / 高清存档，可存自定义预设。
- **JPEG 原生编码（可选，默认关）**：桌面端可切「原生 · 小」，体积能小约 44%，但单张慢数倍——大批量靠并行才划算。

### 修了什么

- **导入**：暂停后继续，不再误报「N 个文件未导入、文件已存在」
- **导入**：进度条不再来回伸缩
- **导出**：211MB 的包从 **98 秒降到约 3 秒**（原来误走了内置压缩）
- **导出**：外置硬盘权限、子目录不存在导致的失败
- **打包**：完成后主动报出生成的文件名（长包名带 `_1`/`_2` 在 Finder 里肉眼难分）

## 安装

1. 双击打开 DMG
2. 把 PicMan 拖进 Applications
3. 从 Applications 启动

**首次运行被拦**（提示「Apple 无法检查是否包含恶意软件」）：
到 系统设置 → 隐私与安全 → 点「仍要打开」；或终端执行
`xattr -d com.apple.quarantine /Applications/PicMan.app`

## 注意事项

1. **系统要求**：macOS 11.0 或更高
2. **未做代码签名**，首次运行需按上面的步骤放行
3. **临时产物目录**：处理结果落在 `~/Library/Caches/com.picman.app/picman-tmp/work-<时间戳>/`，启动时自动清理超过 24 小时的批次。「清空列表」会立刻删掉当前批次的目录
4. **自动更新**：暂不支持
