# 使用说明

> 写给用软件的人，不是写给改代码的人。全流程在本机完成，不联网、不上传。

## 1. 它适合干什么

一次把**几十到上千张**图片按同一套规则处理完：统一格式、压体积、改尺寸、加水印，然后一次性拿出来。

不适合：单张精修（图层、磨皮、修瑕）、视频、GIF 逐帧处理。

## 2. 导入

三种方式，效果一样：

- 把图片或文件夹**直接拖进窗口**
- 点"添加文件"/"添加文件夹"
- 空列表时点中间的大区域选择

支持格式：JPG、JPEG、PNG、WebP、GIF、BMP。单个文件最大 100MB。

导入后列表会显示缩略图、原始体积、像素尺寸。重复文件（同名同大小同时间）会自动跳过，并在上方提示跳过了哪些、为什么。

## 3. 配置（左侧面板）

### 输出格式与质量

- **JPG**：兼容性最好，适合照片。质量 80 左右肉眼无损。
- **PNG**：无损、支持透明，但体积最大。适合图标、截图、需要透明底的图。
- **WebP**：同画质下体积最小，现代浏览器和系统都支持。

质量滑块只对 JPG 和 WebP 有意义，PNG 是无损的。

### 尺寸

- **原始尺寸**：不缩放。
- **固定宽度 / 固定高度**：填一个数值，勾了"保持比例"就按比例算另一边。
- **按比例缩放**：填百分比，比如 50 就是缩到一半。

### 旋转与翻转

旋转可以填任意角度（界面按 45° 步进），翻转分水平、垂直。旋转后画布会自动扩大，不会裁掉边角。

### 水印

- 类型：文字或图片（图片从本地选，会存进配置）。
- 位置：居中、四角、平铺。平铺适合防盗图，会铺满整张。
- 透明度、旋转角度、缩放倍数都可调；文字还能改颜色和字号。

### 其他

- **保留 EXIF**：原图的拍摄信息（相机、GPS、时间）。关掉就是剥离。注意只对 JPG 有效，PNG/WebP 本来就不带这些信息。
- **防止体积变大**：处理后如果反而更大，自动保留原图。默认开启，强烈建议别关。
- **并发数**：同时处理几张。电脑性能好可以调高，但处理时界面会变卡。

## 4. 处理

点"全部处理"。处理中：

- 顶栏和列表下方显示进度、当前文件、剩余时间。
- 可以**暂停**（随时继续）、**终止**（已完成的保留结果）。
- 每一行的状态会变：待处理 → 处理中 → 完成 / 失败。

处理完哪些会显示"保留原图"：体积反而变大、或者是动图（GIF/动图 WebP 为保证不丢动效，直接跳过处理、输出原文件）。

单张想重做，把鼠标移到那一行，点旋转箭头。

## 5. 导出

两种方式：

- **打包下载**：打成 ZIP。桌面版只需**选一次保存目录**，分几个包都写进去，不会逐个弹框。
  - **ZIP 分组**：`整包`（默认，内部保留目录结构）或 `按文件夹`（每个顶层文件夹单独成包，包名用目录名）
  - **打包方式**：`内置`（默认，快）或 `本机压缩`（交系统 `ditto`，省内存、能打超大包，仅桌面版）
- **全部下载**（仅桌面版）：直接写到你选的文件夹，**保留原来的目录结构**。注意：导入时如果拖的是文件夹，导出的结果会带上这层文件夹名。

导出前先选模式：

- **重命名**：在原文件名后加后缀（默认空，可在配置里设），不覆盖原文件。安全。
- **覆盖**：直接替换原文件。**不可撤销**，导出前请确认原图有备份。

## 6. 快捷键

| 按键 | 作用 |
|------|------|
| ⌘A / Ctrl+A | 全选文件 |
| Esc | 关闭当前弹窗 |
| ⌘Q / Ctrl+Q | 退出（有未完成任务会先确认） |
| ⌘W / Ctrl+W | 窗口最小化（不是关闭，应用仍在后台） |
| ⌘H | 隐藏窗口（v1.2.2 失效，v1.3.0 修复） |

## 7. 常见问题

**处理完体积没变小，反而提示"保留原图"**
说明压缩参数太保守，或者原图本身已经压得很狠了。可以调低质量、或者换成 WebP。如果原图是 PNG，转 JPG 通常能小很多。

**GIF 没有被处理**
动图会跳过处理，直接输出原文件。压缩动图会丢掉动画，所以不做。

**导出到外接硬盘失败**
桌面版对可写目录有白名单（主目录、下载、桌面、文档、外接硬盘）。如果目标在别处，先导出到桌面再手动移。

**改了配置但下次打开又变回去了**
配置存在浏览器本地存储里。如果存满了（比如水印图片很大），会保存失败并提示。去"关于 → 本地存储管理"重置一下。

**处理到一半卡住不动**
先点暂停再点继续。仍然不动就终止后重新处理——已完成的不会重做。
