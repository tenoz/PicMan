Tauri WebView 特定说明
============================================================

测试环境: Chromium 145 (通过 Playwright 模拟)
注意: 此测试在 Chromium 环境中运行，与 Tauri 的 WKWebView 环境可能有所不同。

Tauri macOS 使用 WKWebView (WebKit)，其 OffscreenCanvas 支持情况：
- macOS 10.15+ / iOS 13+ 开始支持 OffscreenCanvas
- WebKit 版本需要较新才能完全支持所有特性
- 建议在实际 Tauri 应用中再次验证

降级方案建议 (如 OffscreenCanvas 不可用):
1. 在主线程使用普通 HTMLCanvasElement
2. 使用 requestIdleCallback 分片处理避免阻塞
3. 考虑使用 WebAssembly 加速图片处理
4. 对大量图片采用批量处理+进度反馈策略

实际 Tauri 测试建议:
- 在 Tauri 桌面应用中运行此测试脚本
- 使用 console.log 输出结果
- 检查 macOS WKWebView 的具体版本
