# PicMan v1.2.0 Release Notes

## 🎉 What's New | 新功能

### ✨ Features | 功能

- **批量文件导出** - 支持重命名或直接覆盖原文件
  - Batch file export with rename or overwrite options
  
- **窗口行为优化** - 改进窗口关闭等行为
  - Improved window close behavior

## 📦 Downloads | 下载

### macOS (Apple Silicon)

- **DMG**: `PicMan_1.2.0_aarch64.dmg`
- **Size**: ~2.8 MB
- **Requirements**: macOS 11.0 (Big Sur) or later

## 🚀 Installation | 安装

### macOS

1. Download `PicMan_1.2.0_aarch64.dmg`
2. Double-click to open
3. Drag PicMan.app to Applications folder
4. On first launch, allow in System Settings > Privacy & Security
